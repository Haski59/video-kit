# Video Kit SOPs

Do them in order the first time. After that, each video is SOP 01 → 02 → 03 → 04 → 07 → 08.

| # | SOP | When |
|---|---|---|
| 00 | [Install & Onboarding](00-install-and-onboarding.md) | once per Mac |
| 01 | [Plan A Long-Form Video](01-plan-a-long-form-video.md) | before recording |
| 02 | [Recording](02-record.md) | every recording |
| 03 | [Long-Form Editing](03-edit-long-form.md) | after recording |
| 04 | [Shorts From Long-Form](04-shorts-from-long-form.md) | after the long-form edit |
| 05 | [Standalone Short-Form](05-standalone-short-form.md) | when you record a short on purpose |
| 06 | [Captions & Graphics](06-captions-and-graphics.md) | to adjust the look |
| 07 | [Thumbnails](07-thumbnails.md) | before publishing long-form |
| 08 | [Publish Pack](08-publish-pack.md) | before publishing anything |
| 09 | [QA, Troubleshooting & Updates](09-qa-troubleshooting-and-updates.md) | when something is flagged or breaks |
| 10 | [Copy A Reference Style](10-copy-a-reference-style.md) | when you want your videos made like one you admire |
| 11 | [Faceless Videos](11-faceless-videos.md) | when you want a video without filming |

Each SOP follows the same layout: **Made For · SOP Intention · Process Summary · The Steps Broken Down · Pre-Launch Checklist.**
